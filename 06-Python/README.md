# Python orodja

## SystemOverview.py

Prikaže osnovne podatke o sistemu, procesorju, pomnilniku in prostem prostoru na diskih ter ustvari besedilno poročilo v mapi `Reports`.

### Zahteve
- Python 3.9 ali novejši
- Brez dodatnih paketov (uporablja samo standardno knjižnico)
- Zaženite iz ukazne vrstice:

```powershell
python .\SystemOverview.py
```

Skripta je namenjena pregledu in ne spreminja nastavitev računalnika.
