# Python Tools

## SystemOverview.py

Displays basic information about the system, processor, memory, and available disk space, then creates a text report in the `Reports` directory.

### Requirements

- Python 3.9 or later
- No third-party packages required (uses only the Python standard library)
- Run from the command line:

```powershell
python .\SystemOverview.py
```

This script is intended for inspection only and does not modify system settings.
